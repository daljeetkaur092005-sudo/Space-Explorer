# Space Explorer

Space Explorer is a web application built with React that allows users to explore space-related images and discover more about the universe using NASA APIs.

## Features

- Explore featured NASA content.
- Search for space images by keywords.
- View images with titles and descriptions.
- Discover information about planets, stars, and galaxies.
- Responsive design with a dark theme and golden accents.

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- React Router
- TanStack Query
- Axios
- NASA APIs

## What I Learned

Working on this project helped me practice API integration, data fetching, state management, routing, and responsive UI development.

## APIs Used

- [NASA Science](https://science.nasa.gov/)
- [NASA Images and Video Library](https://images.nasa.gov/)
